# Landings conceptuales de NexoNet

Diseños y marcas de ejemplo creados para esta beta. No son clientes, encargos ni resultados reales. Las fotografías son ilustrativas y no representan trabajos de las marcas ficticias.

- `photos/cafe.jpg`: Hanny Naibaho, [Unsplash](https://unsplash.com/photos/flat-lay-photography-of-coffee-latte-in-teacup-on-table-0YbeoQOX89k).
- `photos/architecture.jpg`: Miguel Joya, [Unsplash](https://unsplash.com/photos/modern-white-building-with-curved-architectural-lines-f5gQ0_8DC0M).
- `photos/cycling.jpg`: Rob Wingate, [Unsplash](https://unsplash.com/photos/cyclist-rides-a-bike-along-a-forest-road-MXl86dgC_js).

Fotografías descargadas desde las páginas indicadas, identificadas como gratuitas bajo la [licencia Unsplash](https://unsplash.com/license). Se sirven localmente, sin API ni clave. Las fotos de Brote conservan sus créditos en `../demos/CREDITS.md`. La escena de Habita y los gráficos de Órbita son geometría propia de HTML/CSS/SVG.

Los archivos `*-landing.jpg` se renderizan desde las composiciones propias de `scripts/render-concept-landings.mjs`; no son capturas de webs de terceros.
